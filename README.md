#Video Game API

A REST API used to manage a collection of video games. A client application can create, list, update, and delete game records via HTTP. Every request requires an API key, as well.

Azure-hosted base URL: `https://func-videogames-dev-001-fda9awdbawbddmeb.centralus-01.azurewebsites.net/api`

## Endpoints

Create a game: `POST` `/api/games` --> `201 Created'
Get all games: `GET` `/api/games` --> `200 OK'
Update a game: `PUT` `/api/games/{id}` --> `200 OK`
Delete a game: `DELETE` `/api/games/{id}` --> `200 OK`

Possible error responses: `400` (invalid data), `401` (missing or invalid API key), `404` (unknown game ID), and `500` (server API key not configured).
Errors are returned as JSON. For example, `{"error": "Missing or invalid API key."}`.

## Game fields

`id` (string (UUID)): Generated by the server and assigned when a game is created
`title` (string)
`developer` (string)
`releaseDate` (string): `YYYY-MM-DD`
`price` (number): Must be zero or greater

## Authentication

Send your API key in the `x-api-key` header on every request:

```
x-api-key: YOUR_API_KEY
```

The key is read from the `API_KEY` application setting. It is never stored in the source code or committed to this repository.

## Example requests

Create a game:

```bash
curl -X POST "https://func-videogames-dev-001-fda9awdbawbddmeb.centralus-01.azurewebsites.net/api/games" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"title": "Undertale", "developer": "Toby Fox", "releaseDate": "2015-10-15", "price": 9.99}'
```

List all games:

```bash
curl "https://func-videogames-dev-001-fda9awdbawbddmeb.centralus-01.azurewebsites.net/api/games" -H "x-api-key: YOUR_API_KEY"
```

## How to run locally

**Prerequisites:** Python 3.11 and [Azure Functions Core Tools](https://learn.microsoft.com/azure/azure-functions/functions-run-local) v4.

1. Install the dependencies:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

2. Create a `local.settings.json` file in a project folder (excluded from git) and choose your own API key:

   ```json
   {
     "IsEncrypted": false,
     "Values": {
       "AzureWebJobsStorage": "",
       "FUNCTIONS_WORKER_RUNTIME": "python",
       "API_KEY": "choose-a-long-random-value"
     }
   }
   ```

3. Start the app:

   ```bash
   func start
   ```

   The API is then available at `http://localhost:7071/api/games`.

## Deployment

The Function App was created in the Azure portal using the Flex Consumption plan. The project was deployed from Visual Studio Code with the Azure Functions extension (Deploy to Function App). After deploying, the `API_KEY` application setting must be added in the Azure portal under Settings > Environment variables.

## Notes

- Games are stored in an in-memory list, so no database is needed. Data is lost when the app restarts or scales, which is expected for this project.
- Azure resource names follow Microsoft's Cloud Adoption Framework naming pattern.
